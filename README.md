# 국시 모험: 밤의 실기숲

신유의 압박면접 — 발판을 오르고 의료 도구로 싸우며 내 CC 대본을 떠올리는 2D 횡스크롤 회상 게임.

**플레이:** https://sffs123-byte.github.io/recall-barrage-demo/?v=sidequest-3

## 조작

- **←/→ 또는 A/D:** 좌우 이동. **Space/W/↑:** 이단 점프. **↓/S:** 숙이기. 발판에서 아래+점프는 내려가기.
- **Z:** 기본 공격(누르고 있으면 연속). **Shift:** 무적 회피.
- **Q/E/F:** 청진기 / DTR 반사망치 / 펜라이트 선택. **R:** 다음 무기.
- **X:** 선택한 무기의 스킬. 청진기=3초 공명 보호막, 반사망치=충격파·기절, 펜라이트=집중빔. 재사용 대기시간은 각각8/6/7초.
- **C:** 기력100일 때 종합진찰. 위험 제거·보스 공격·집중력10회복. 회상 반격 및 적중으로 충전.
- **Enter:** 원문 보기 → 다시 Enter: 떠올렸어·다음.
- 원문 확인 뒤 **2 / Backspace / Shift+Enter:** 놓쳤어·다음. **P / Esc:** 일시정지.
- 휴대폰은 좌우 조이스틱과 숙이기·공격·점프·회피 버튼, 무기·스킬·궁극기 버튼을 제공합니다. 가로 화면은 전투 왼쪽/회상 오른쪽입니다.

## 전투

4,600 길이의 스크롤 맵, 중력·발판·이단 점프. 보스 체력과3페이즈, 격파 후 다음 라운드로 이어집니다. 8가지 공격은 발동 전 위치와 회피법을 표시합니다: 지면 충격파, 돌진, 도약 내려찍기, 낙제 도장 낙하, 상단 레이저, 바닥 쓸기, 분신 소환, 양옆 장벽. 난이도에 따라 피해량·예고시간·공격 간격이 달라집니다. 방사형 탄막/자동 사격은 없습니다.

문제 회상·원문 확인 중에도 전투는 계속됩니다. 집중력이0이면 회복하며 학습 진도는 유지됩니다. 보스를 격파해도 학습은 끝나지 않습니다. 수동 공격·스킬 사용은 학습 성적에 반영하지 않습니다.

## 회상 범위

총 **3,413개 항목**. CC61개, 공통17개 구분 중 실제 내용15개, 증례83개를 포함합니다. OSCE 독립 술기자료는 제외합니다.

- 한줄 핵심59개 + 신체진찰 한줄57개 = **116개** 원문 유지.
- **댓글·주석 설명을 떠올리는78개 문항 제거.**
- 한줄 이외 강조가 있는137개 개별 행을 **CC별50개 묶음**으로 통합. 질문은 “○○ CC에서 내가 강조해 놓은 것들이 뭔지 떠올려.” 원문 공개 전 항목별 단서를 주지 않습니다.
- 묶음 답안은 원래 강조 행 전체와 노랑1/주황2/빨강3의 정확한 위치를 보존합니다. 원래 강조가 없는 CC에는 가짜 강조 문제를 만들지 않습니다.
- 나머지 전체 대본·신체진찰·교육·증례 진단/감별/검사/치료 원문은 유지합니다. 선택지·자동채점·자동 시간초과는 없습니다.

놓친 항목은 다른 항목 최대3개 뒤에 다시 나오며, 모든 항목을 한 번 이상 ‘떠올렸어’로 확인할 때까지 계속합니다. 중요도 색은 사용자의 개인 강조이며 실제 시험의 위험도 판정이 아닙니다.

## 저장과 데이터

진행은 같은 브라우저에 저장하며 기기 간 동기화는 없습니다. 기존v2 진도에서 유지된 문항의 완료기록을 이전합니다. 새 강조 묶음은 구성한 모든 기존 문항이 완료된 경우만 완료로 인정합니다. 댓글 문항은 대기열에서 제외하고 옛 저장값은 백업으로 보존합니다. 명시적 초기화는 이 게임의v2/v3 진행 저장값만 지웁니다.

사용자가 이전에 GitHub 체험판에 게시하도록 요청한 학습 텍스트만 재구성합니다. 로그인정보·쿠키·계정식별자·사진·내부 PDF·CNU 복습기록은 포함하지 않습니다. CNU에 접속하거나 기록을 변경하지 않습니다. 기존 신유 액션 게임도 별도 유지합니다.

범위 요약은 [coverage.json](coverage.json), 음악은 [AUDIO.md](AUDIO.md).

## 실행

추가 라이브러리 없이 기존 Canvas 엔진과 정적 파일을 사용합니다. 별도빌드/학습 API/외부 자산 서비스가 필요 없습니다.

```sh
python3 -m http.server 8774 --bind 127.0.0.1
```

GitHub Pages는 main 브랜치 루트입니다. 로컬127.0.0.1/localhost에서만 `?qa=1` 검증 제어가 노출됩니다. 공개 사이트에는 검증 제어가 없습니다.
