# 국시 탄막: 생각하면서 피해

신유의 압박면접 — 탄막을 피하면서 실기 핵심을 떠올리는 2~3분 체험판.

https://sffs123-byte.github.io/recall-barrage-demo/

## 플레이

- WASD / 방향키 이동, Space 회피, 1~3 답, Enter 보기/원문 열기, P 일시정지.
- 휴대폰: 왼쪽 조이스틱으로 이동하면서 답 버튼과 회피를 터치.
- 공격은 자동. 맞히면 기억 반격과 체력 회복.
- 문제·정답·한줄 원문 확인 중에도 탄막은 계속 진행됩니다.
- 키워드 선택 문제와 한줄 대본 자기확인 결과는 따로 표시합니다. 음성 자동 채점은 없습니다.
- 틀린 핵심은 같은 판 뒤쪽에 최대3개 재등장합니다.

## 체험 범위

기침, 호흡곤란, 급성복통의 사용자 제공 한줄 핵심 및 강조 키워드만 추려 담았습니다.
색은 사용자 지정 중요도이며, 한줄 핵심 > 빨강3 > 주황2 > 노랑1입니다. 이 세 주제의 발췌에는 주황 항목이 없어서 임의로 만들지 않았습니다.
의학적 중증도나 공식 시험 배점으로 해석하지 않습니다. 본인의 압축어는 그대로 보존합니다.

- CNU 로그인/쿠키/대본 전체/댓글 DB/복습기록은 포함하지 않습니다.
- 원래 신유 액션 게임과 별개인 임시 체험판 저장소입니다.
- CNU와 통신하거나 진도를 기록하지 않습니다. 기록은 현재 판 메모리에만 있습니다.
- 실존 인물의 실제 이력과 무관한 가상 패러디이며, 실제 시험 채점 도구가 아닙니다.

## 파일

`deck.js` 학습 발췌, `study.js` 회상 흐름, `arena.js` Canvas 전투, `index.html`/`style.css` 화면.
순수 정적 파일로 빌드/서버/API/DB가 필요 없습니다. 향후 CNU에 옮길 때는 deck 공급 부분을 계정의 원문 읽기로 교체할 수 있습니다.

```sh
python3 -m http.server 8771 --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:8771 을 엽니다.

GitHub Pages: main 브랜치 루트. 체험 종료 후 게시 중단/저장소 삭제는 별도로 수행합니다.
