# 국시 탄막: CC 전범위 회상

신유의 압박면접 — 탄막을 피하면서 내 실기 대본을 꺼내는 자기회상 게임.

**플레이:** https://sffs123-byte.github.io/recall-barrage-demo/

## 조작

- WASD / 방향키 이동, Space 회피, P / Esc 일시정지.
- **Enter: 원문 보기 → 다시 Enter: 떠올렸어·다음.**
- 원문 확인 뒤 **2 / Backspace / Shift+Enter: 놓쳤어·다음**.
- 휴대폰은 왼손 조이스틱과 오른손 원문·자기확인 버튼을 동시에 사용합니다.
- 선택지·자동채점·자동 시간초과는 없습니다. 답을 보기 전에 떠올렸는지 스스로 확인합니다.
- 문제를 생각할 때와 원문 확인 중에도 탄막은 계속됩니다. 공격은 자동이며 회상 확인 시 반격합니다.

## 진행

총 **3,578개 회상 항목**. 시간제한과 패배 종료 없이, 모든 항목을 한 번 이상 ‘떠올렸어’로 확인할 때까지 계속합니다.
놓친 항목은 다른 항목 최대3개 뒤에 다시 나오며 반복 횟수 제한이 없습니다. 집중력이0이 되어도 회복하고 진도는 유지합니다.

진행·현재 항목·누적 시간은 **같은 브라우저에 자동 저장**합니다. 새로고침하거나 나중에 다시 열어 이어 할 수 있습니다. 기기 간 동기화는 하지 않습니다. 첫 화면의 기록 초기화는 이 게임의 저장값만 지우며, CNU에는 영향을 주지 않습니다.

## 포함 범위

- CC61개 전체와 공통대본17개 구분 점검: 실제 내용이 있는 공통대본15개 수록. 나머지2개는 제목만 있는 구분자입니다.
- 본인 한줄 핵심59개와 신체진찰 한줄57개, 전체 문진·신체진찰·교육 대본, 사용자 메모.
- 노랑1 / 주황2 / 빨강3 강조를 원래 행과 함께 보존. 한줄 핵심이 최우선이며 색은 개인 중요도입니다.
- 등록 증례83개: 소수 단서로 진단 후보 회상, 감별·검사·치료·교육, 신체진찰, 상세복기 및 체크리스트.
- **OSCE 독립 술기자료는 제외**합니다. CC에 원래 포함된 신체진찰은 포함합니다.

[범위 목록](coverage.json)에 항목별 수록 현황을 기록했습니다. 개인 수정본이 있으면 기본본보다 우선했습니다. 원문에 없는 한줄·증례 단서·진찰 결과는 만들지 않았습니다. 진단 단서가 빈약한 경우 확진 문제가 아니라 등록된 원문 후보 회상으로 표시합니다. 현재 정리 답안, 당시 복기, 동일 증례인지 미확정인 관련 복기, 보관 체크리스트는 서로 구분합니다.

## 데이터와 구성

사용자가 GitHub 체험판으로 요청한 CC 학습 텍스트만 포함합니다. 로그인정보, 쿠키, 계정 식별자, 원본 사진, 내부 PDF·첨부파일, CNU 복습기록은 게시하지 않습니다. CNU에 접속하거나 기록을 변경하지 않습니다.

- `deck.js`: 원문에서 추출한 회상 항목과 강조 위치
- `study.js`: 자기회상·재출제·브라우저 저장
- `arena.js`: Canvas 전투
- `index.html`, `style.css`: PC·모바일 화면

순수 정적 파일로 빌드나 학습 API가 필요 없습니다. 로컬 실행:

```sh
python3 -m http.server 8771 --bind 127.0.0.1
```

GitHub Pages는 main 브랜치 루트입니다. 별도 체험판 저장소이며 기존 신유 액션 게임은 변경하지 않습니다. 추후 CNU 이전 또는 체험판 게시 중단은 별도로 진행합니다.
